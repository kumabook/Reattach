Apple Watch

一つの tmux を、どの端末でも同じように。

机で作業を始めて、ソファで様子を見て、手首で応答する。どの端末にも、同じセッションと同じ許可待ちが並びます。

💻

Mac

メニューバーに常駐します。すべてのマシンの許可待ちと作業中のペインを一覧で見て、目的のターミナルを探さずにその場で応答できます。

📱

iPhone・iPad

セッション、ウィンドウ、ペインを tmux と同じ配置で表示。自分のプレフィックスとキーバインドで、補助キーでも外部キーボードでも入力できます。ホーム画面のウィジェットで許可待ちがわかります。

⌚️

Apple Watch

通知で気づいて、内容を読み、選択肢を押すだけ。文字盤のコンプリケーションやスマートスタックに、許可待ちの件数が出ます。

tmux そのまま。余計なものはありません。

Reattach は、ターミナルを置き換えたり、エージェントを包み込んだりしません。いま動いている tmux につなぐだけです。

  • セッションはそのまま

    新しいシェルも、チャット画面も、プロジェクトごとの設定もいりません。ペインで動いているものが、そのまま見えます。

  • エージェントを選ばない

    Claude Code でも Codex でも、tmux で動くものなら何でも。Claude Code と Codex の許可待ちはすべての端末に届き、届いたその場で応答できます。

  • キー操作もいつもどおり

    プレフィックスもキーバインドも、机の前と同じように効きます。copy mode はクリップボードと連携し、日本語入力も画面のキーボードと外部キーボードの両方で使えます。

  • 自分のマシンに直接つながる

    reattachd はオープンソースで、自分の Mac や Linux で動きます。Tailscale か Cloudflare Tunnel で直接つながり、間に中継サーバーを挟みません。

2 ステップで始める

tmux を動かしているコンピュータに reattachd を入れます。reattachd init が、接続の設定、常駐の登録、Claude Code と Codex の通知フックの導入、QR コードの表示までを案内します。

コンピュータで実行する

# macOS
brew install kumabook/reattach/reattachd
reattachd init

# Linux
curl -fsSL https://raw.githubusercontent.com/kumabook/Reattach/main/install.sh | sh
reattachd init

Tailscale が入っていれば自動で使います。Cloudflare Tunnel を使う場合は reattachd init --url https://あなたのホスト を実行してください。詳しくはセットアップガイドへ。

QR コードを読み取る

iPhone で Reattach を開いて読み取ります。Apple Watch には iPhone から接続先が共有されます。同じ Mac の Reattach for Mac は、reattachd init がそのままつなぎます。別の Mac からつなぐときは、QR コードの下に表示される URL を設定画面に貼り付けます。
