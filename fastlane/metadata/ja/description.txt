いつもの tmux に、どこからでも戻れる。

Reattach は、いま使っている tmux を iPhone・iPad・Apple Watch で扱えるアプリです。新しいターミナルもチャット画面もありません。机の前と同じセッション、同じキー操作で、Claude Code や Codex の許可待ちにどこからでも応答できます。

【tmux をそのまま】
• セッション、ウィンドウ、ペインを一覧表示。tmux と同じペイン配置で表示し、タップで選択
• 設定済みのプレフィックスやキーバインドで直接入力
• 画面のキーボードでは esc・ctrl・tab・矢印などの補助キーを表示。外部キーボードのショートカットにも対応
• 日本語の変換入力や長い文章に便利な文章入力モード
• tmux の copy mode の選択範囲を表示し、コピーを確定すると端末のクリップボードにも反映
• 自動再接続と接続状態の表示

【コーディングエージェントに応答】
• Claude Code・Codex の許可待ちをプッシュ通知でお知らせ
• すべてのサーバーの許可待ちを一つの一覧で確認し、その場で選択肢を送信
• ホーム画面のウィジェットで許可待ちと新着のペインを確認
• エージェントが作業中のペインを表示

【Apple Watch】
• 許可待ちの一覧と内容を手元で確認
• 選択肢を押して応答（Reattach Pro）
• 文字盤のコンプリケーションとスマートスタックに許可待ちの件数を表示

【2 ステップで始める】
1. tmux を動かしている Mac か Linux で reattachd を入れ、reattachd init を実行
2. 表示された QR コードをアプリで読み取る
通信は HTTPS だけです。Tailscale があればそのまま使え、なくても Cloudflare Tunnel でポートを開けずに外から届きます。iPhone に VPN アプリは要らず、Reattach の中継サーバーも挟みません。reattachd は無料・オープンソースです。

【Mac でも同じように】
Reattach for Mac（無料）を使うと、Mac のメニューバーからも同じ許可待ちに応答できます。

【Reattach Pro（買い切り）】
• サーバー数の制限なし（無料版は 1 台）
• Apple Watch から応答
• 保存コマンド数の制限なし（無料版は 5 件）

【必要な環境】
• tmux を実行する Mac または Linux
• reattachd 2.1.0 以降（Apple Watch アプリと reattachd init に必要）

日本語と英語に対応しています。

セットアップ方法：https://reattach.tmux.kumabook.tokyo/ja/setup.html
